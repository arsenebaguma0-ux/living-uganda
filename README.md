# Living Uganda

Preliminary static website and Uganda species inventory.

Open index.html through a local HTTP server; species search loads data/species.json. No API key, subscription or backend service is needed to serve the site.

For GitHub Pages, publish the main branch from the repository root. All asset paths are relative.

The inventory is assembled from attributed Uganda datasets. See dataset-credits.html for reuse terms. Photography and fonts have separate credits/licences; do not apply one blanket licence to all assets.

Update the editable HTML, CSS, JavaScript and data files locally, then commit and push updates to publish them.
